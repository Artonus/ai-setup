# ai-setup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A public repo with shared Claude Code + OpenCode configuration and a portable `install.sh` that symlinks it into `$HOME`, optionally layering a private work overlay on top.

**Architecture:** Config lives in `shared/` (read by both tools), `claude/` and `opencode/` (tool-specific). `install.sh` symlinks files and directory entries into `~/.claude` and `~/.config/opencode`, records everything it creates in a manifest (so it can back up foreign files, prune stale links, and uninstall precisely), and, when `$AI_SETUP_OVERLAY` is set, resolves each path to the overlay first and deep-merges the two JSON configs with `jq`.

**Tech Stack:** bash (3.2-compatible), jq, plain-bash test runner (no bats).

**Spec:** `docs/superpowers/specs/2026-10-02-ai-setup-design.md`

## Global Constraints

- Targets: macOS (bash 3.2, BSD userland) and Ubuntu. No `readlink -f`, no `mapfile`, no associative arrays, no empty-array expansion under `set -u`, no GNU-only flags.
- `jq` is the only non-base dependency, and is only required when an overlay supplies a JSON config.
- Public repo: no tokens, API keys, internal URLs, or company-specific rules in any file. Secrets are referenced as `{env:VAR}` (OpenCode) or `${VAR}` (Claude Code).
- Same-named overlay files replace base files; `settings.json` / `opencode.json` are deep-merged (objects merged, arrays unioned, overlay scalars win).
- Existing foreign files are backed up (`<path>.bak.<YYYYmmddHHMMSS>`), never deleted.
- `--dry-run` changes nothing on disk; `--uninstall` removes only what the manifest lists.
- Every path is quoted: `$HOME` and the repo path may contain spaces (the tests use paths with spaces).
- End every commit message with a second `-m` of `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

Failure modes the spec implies but a casual test list would miss. Each has a test in the task noted.

1. `~/.claude/skills` (or any target dir) is already a symlink to a directory: the installer must not write links through it into the other location. (Task 2)
2. A skill is deleted from the repo: its link in `~/.claude` / `~/.config/opencode` must not be left dangling. (Task 3)
3. `AI_SETUP_OVERLAY` is set but wrong (typo): fail loudly instead of silently installing the base only. (Task 4)
4. Overlay `permissions.deny` must add to base denies, never replace them. (Task 4)
5. Overlay JSON is malformed: fail before touching anything, not half-way through an install. (Task 4)
6. The overlay is dropped on a later run: the generated merged JSON returns to a plain symlink without leaving `.bak` clutter. (Task 4)

```bash
#!/usr/bin/env bash
# Shared helpers for the plain-bash test suite. Sourced by tests/run.sh.

ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd -P)"
PASS=0
FAIL=0

ok() { PASS=$((PASS + 1)); }
fail() { FAIL=$((FAIL + 1)); printf '  FAIL: %s\n' "$*"; }

assert_eq() { # assert_eq <expected> <actual> <message>
  if [ "$1" = "$2" ]; then ok; else fail "$3 (expected '$1', got '$2')"; fi
}

assert_link() { # assert_link <path> <expected-target>
  if [ -L "$1" ] && [ "$(readlink "$1")" = "$2" ]; then
    ok
  else
    fail "$1 should be a symlink to $2 (readlink: '$(readlink "$1" 2>/dev/null)')"
  fi
}

assert_missing() { # assert_missing <path>
  if [ -e "$1" ] || [ -L "$1" ]; then fail "$1 should not exist"; else ok; fi
}

assert_file() { # assert_file <path>: regular file, not a symlink
  if [ -f "$1" ] && [ ! -L "$1" ]; then ok; else fail "$1 should be a regular file"; fi
}

assert_contains() { # assert_contains <haystack> <needle> <message>
  case $1 in
    *"$2"*) ok ;;
    *) fail "$3 (output did not contain '$2'; output was: $1)" ;;
  esac
}

count_backups() { # count_backups <path>: how many <path>.bak.* entries exist
  local n=0 f
  for f in "$1".bak.*; do
    if [ -e "$f" ] || [ -L "$f" ]; then n=$((n + 1)); fi
  done
  echo "$n"
}

# Fresh sandbox: temp dir (symlinks resolved, as install.sh uses pwd -P), a HOME
# and a copy of the repo, both with spaces in the path to exercise quoting.
new_env() {
  T="$(cd "$(mktemp -d "${TMPDIR:-/tmp}/ai-setup-test.XXXXXX")" && pwd -P)"
  export HOME="$T/my home"
  mkdir -p "$HOME"
  unset XDG_CONFIG_HOME XDG_STATE_HOME AI_SETUP_OVERLAY
  REPO="$T/ai setup"
  mkdir -p "$REPO"
  cp -R "$ROOT/install.sh" "$ROOT/shared" "$ROOT/claude" "$ROOT/opencode" "$REPO/"
  mkdir -p "$REPO/shared/skills/demo"
  printf '# demo skill\n' > "$REPO/shared/skills/demo/SKILL.md"
  printf 'say hello\n' > "$REPO/shared/commands/hello.md"
}

run_install() { # run_install [install.sh args]: sets RC and OUT
  RC=0
  OUT="$(bash "$REPO/install.sh" "$@" 2>&1)" || RC=$?
}
```

```bash
#!/usr/bin/env bash
# Install Claude Code + OpenCode config from this repo by symlinking into $HOME.
# Portable to macOS (bash 3.2, BSD userland) and Ubuntu. See README.md.
set -euo pipefail

REPO="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd -P)"
CLAUDE_DIR="$HOME/.claude"
OPENCODE_DIR="${XDG_CONFIG_HOME:-$HOME/.config}/opencode"
STATE_DIR="${XDG_STATE_HOME:-$HOME/.local/state}/ai-setup"
MANIFEST="$STATE_DIR/manifest"
STAMP="$(date +%Y%m%d%H%M%S)"
DRY_RUN=0
CHANGES=0
NEW_MANIFEST=""

usage() {
  cat <<'EOF'
Usage: install.sh [--dry-run]

Symlinks the shared Claude Code / OpenCode config into ~/.claude and
~/.config/opencode. Existing files are backed up, never deleted.

  --dry-run    Show what would change; touch nothing.
  -h, --help   Show this help.
EOF
}

die() { printf 'ai-setup: %s\n' "$*" >&2; exit 1; }
log() { printf '%s\n' "$*"; }

# act <description> <command...>: run a mutating command (or just report it in dry-run).
act() {
  local desc=$1
  shift
  CHANGES=$((CHANGES + 1))
  if [ "$DRY_RUN" = 1 ]; then
    log "would $desc"
  else
    "$@"
    log "$desc"
  fi
}

# owned <path>: true when a previous run created <path>.
owned() { [ -f "$MANIFEST" ] && grep -qxF -- "$1" "$MANIFEST"; }

# record <path>: remember that this run manages <path> (also in dry-run, so pruning can be planned).
record() { printf '%s\n' "$1" >> "$NEW_MANIFEST"; }

# clear_dest <path>: make room at <path>. Our own old output is removed; anything else is backed up.
clear_dest() {
  local dest=$1
  if [ ! -e "$dest" ] && [ ! -L "$dest" ]; then return 0; fi
  if owned "$dest"; then
    act "remove $dest" rm -f "$dest"
  else
    act "back up $dest to $dest.bak.$STAMP" mv "$dest" "$dest.bak.$STAMP"
  fi
}

make_link() { mkdir -p "$(dirname "$2")" && ln -s "$1" "$2"; }

# link <src> <dest>: idempotent symlink with backup of whatever is in the way.
link() {
  local src=$1 dest=$2
  record "$dest"
  if [ -L "$dest" ] && [ "$(readlink "$dest")" = "$src" ]; then return 0; fi
  clear_dest "$dest"
  act "link $dest -> $src" make_link "$src" "$dest"
}

# OpenCode directory name for each shared kind (checked against the OpenCode docs in Task 5).
opencode_subdir() {
  case $1 in
    skills) echo skills ;;
    agents) echo agents ;;
    commands) echo commands ;;
    *) die "unknown kind: $1" ;;
  esac
}

# src_for <area> <rel>: where <area>/<rel> comes from.
src_for() { printf '%s\n' "$REPO/$1/$2"; }

# children <area> <subdir>: entry names inside <area>/<subdir>.
children() { ls -1 "$REPO/$1/$2" 2>/dev/null | grep -v '^\.gitkeep$' || true; }

# link_children <area> <kind> <destdir>: link every entry of <area>/<kind> into <destdir>.
link_children() {
  local name
  # A symlinked target dir would make us write through it into somewhere else.
  if [ -L "$3" ]; then clear_dest "$3"; fi
  while IFS= read -r name; do
    [ -n "$name" ] || continue
    link "$(src_for "$1" "$2/$name")" "$3/$name"
  done < <(children "$1" "$2")
}

# install_json <area> <name> <dest>: install a JSON config.
install_json() { link "$(src_for "$1" "$2")" "$3"; }

install_all() {
  local kind
  link "$(src_for shared AGENTS.md)" "$CLAUDE_DIR/AGENTS.md"
  link "$(src_for claude CLAUDE.md)" "$CLAUDE_DIR/CLAUDE.md"
  install_json claude settings.json "$CLAUDE_DIR/settings.json"
  link "$(src_for shared AGENTS.md)" "$OPENCODE_DIR/AGENTS.md"
  install_json opencode opencode.json "$OPENCODE_DIR/opencode.json"
  for kind in skills agents commands; do
    link_children shared "$kind" "$CLAUDE_DIR/$kind"
    link_children shared "$kind" "$OPENCODE_DIR/$(opencode_subdir "$kind")"
  done
}

write_manifest() {
  if [ "$DRY_RUN" = 1 ]; then return 0; fi
  mkdir -p "$STATE_DIR"
  sort -u "$NEW_MANIFEST" > "$MANIFEST"
}

main() {
  while [ $# -gt 0 ]; do
    case $1 in
      --dry-run) DRY_RUN=1 ;;
      -h|--help) usage; exit 0 ;;
      *) die "unknown option: $1" ;;
    esac
    shift
  done

  NEW_MANIFEST="$(mktemp "${TMPDIR:-/tmp}/ai-setup.XXXXXX")"
  trap 'rm -f "$NEW_MANIFEST"' EXIT

  install_all
  write_manifest

  if [ "$DRY_RUN" = 1 ]; then
    log "ai-setup (dry run): $CHANGES change(s) planned"
  else
    log "ai-setup: $CHANGES change(s)"
  fi
}

main "$@"
```

```bash
    if grep -qxF -- "$path" "$NEW_MANIFEST"; then continue; fi
    if [ -L "$path" ] || [ -f "$path" ]; then act "remove stale $path" rm -f "$path"; fi
  done < "$MANIFEST"
}

# uninstall: remove everything the manifest lists. Backups made earlier are left in place.
uninstall() {
  if [ ! -f "$MANIFEST" ]; then
    log "nothing to uninstall"
    return 0
  fi
  local path
  while IFS= read -r path; do
    if [ -L "$path" ] || [ -f "$path" ]; then act "remove $path" rm -f "$path"; fi
  done < "$MANIFEST"
  act "remove manifest $MANIFEST" rm -f "$MANIFEST"
}
```

```bash
# Deep merge of two JSON documents (slurped as .[0] base, .[1] overlay):
# objects merge recursively, arrays are unioned, other values come from the overlay.
MERGE_JQ='def merge($a; $b):
  if ($a|type) == "object" and ($b|type) == "object" then
    reduce ($b|keys_unsorted[]) as $k ($a;
      .[$k] = (if has($k) then merge(.[$k]; $b[$k]) else $b[$k] end))
  elif ($a|type) == "array" and ($b|type) == "array" then
    reduce $b[] as $x ($a; if index([$x]) == null then . + [$x] else . end)
  else $b end;
merge(.[0]; .[1])'
```

```bash
place_copy() { mkdir -p "$(dirname "$2")" && cp "$1" "$2"; }

# write_generated <tmpfile> <dest>: install a generated regular file (idempotent).
write_generated() {
  local tmp=$1 dest=$2
  record "$dest"
  if [ -f "$dest" ] && [ ! -L "$dest" ] && cmp -s "$tmp" "$dest"; then return 0; fi
  clear_dest "$dest"
  act "write $dest (merged with overlay)" place_copy "$tmp" "$dest"
}

# install_json <area> <name> <dest>: symlink the base config, or write base+overlay merged.
install_json() {
  local base="$REPO/$1/$2" over="" tmp
  if [ -n "${AI_SETUP_OVERLAY:-}" ] && [ -f "$AI_SETUP_OVERLAY/$1/$2" ]; then
    over="$AI_SETUP_OVERLAY/$1/$2"
  fi
  if [ -z "$over" ]; then
    link "$base" "$3"
    return 0
  fi
  tmp="$(mktemp "${TMPDIR:-/tmp}/ai-setup-json.XXXXXX")"
  jq -s "$MERGE_JQ" "$base" "$over" > "$tmp"
  write_generated "$tmp" "$3"
  rm -f "$tmp"
}

# preflight_overlay: fail early, before any change, on a bad overlay.
preflight_overlay() {
```
